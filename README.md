# Windows Explorer Media Converter
Work in progress app to convert media from windows file explorer context menu

if you want to use it right now you have to:
1. build it from source
2. make sure you have ffmpeg and ffprobe in your path enviorment variables  
   you can do that with `winget install FFmpeg`
3. Run the app as administrator to set up windows registry entries

after that use can use the app from the context menu on any media files

proper release and documentation will be available when they will be available
